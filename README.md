
# 🛍️ مشروع Shop

مرحبًا بك في مشروع **Shop** — موقع ويب بسيط للتجارة الإلكترونية تم تطويره باستخدام HTML وCSS وJavaScript. يهدف هذا المشروع إلى توفير تجربة تسوق إلكتروني سلسة وسهلة الاستخدام.

## 📁 هيكل المشروع

```
shop/
├── css/                  # ملفات التنسيق (CSS)
├── js/                   # ملفات JavaScript
├── images/               # الصور المستخدمة في الموقع
└── index.html            # الصفحة الرئيسية للموقع
```

## 🚀 الميزات

- تصميم متجاوب يعمل على مختلف الأجهزة.
- استخدام HTML وCSS وJavaScript لتطوير واجهة المستخدم.
- تنظيم الكود بطريقة تسهل الصيانة والتطوير.

## 🧰 التقنيات المستخدمة

- **HTML**: لبناء هيكل صفحات الويب.
- **CSS**: لتنسيق وتصميم صفحات الويب.
- **JavaScript**: لإضافة التفاعلية إلى صفحات الويب.

## 🛠️ كيفية التشغيل

1. **استنساخ المستودع:**

   ```bash
   git clone https://github.com/KarimEhab100/shop.git
   cd shop
   ```

2. **فتح الموقع:**

   افتح ملف `index.html` في متصفحك المفضل لعرض الموقع.
