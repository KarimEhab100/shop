
# 🛍️ Shop Project

Welcome to the **Shop** project — a simple e-commerce website built using HTML, CSS, and JavaScript. This project aims to provide a smooth and user-friendly shopping experience.

## 📁 Project Structure

```
shop/
├── css/                  # CSS styling files
├── js/                   # JavaScript files
├── images/               # Images used in the website
└── index.html            # Main homepage of the website
```

## 🚀 Features

- Responsive design that works across devices.
- Built with HTML, CSS, and JavaScript.
- Clean and organized code structure.

## 🧰 Technologies Used

- **HTML**: Structure of the web pages.
- **CSS**: Styling and design of the pages.
- **JavaScript**: Interactivity for the website.

## 🛠️ How to Run

1. **Clone the repository:**

   ```bash
   git clone https://github.com/KarimEhab100/shop.git
   cd shop
   ```

2. **Open the site:**

   Open the `index.html` file in your preferred web browser to view the website.
